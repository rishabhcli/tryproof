TryProof

A try-on that checks itself against your skin.

Skin AI reads the face and sets the virtual makeup. Then it scores the rendered result again. If a setting makes a concern look worse, TryProof backs it off before you buy anything.

  1. ReadSkin Analysis scores 8 concerns, Color Tones finds the shade.
  2. PrescribeScores set the Makeup Try-On: smoothing, coverage, glow, under-eye.
  3. ProveSkin Analysis scores the render. Worse? It backs off and re-renders.

Run it on your own selfie

Uses your own YouCam API key (about 45 to 70 units per run). The key stays in this tab, goes only to the proxy for each request and is never stored. Your photo is sent to YouCam to be analyzed and is not kept by this site.
